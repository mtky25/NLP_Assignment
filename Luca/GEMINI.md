# PoliMillionaire NLP Assignment

## Project Overview
This project involves developing an automated chatbot to compete in "Who wants to be a PoliMillionaire?", an online quiz game. The goal is to build a system that can answer Natural Language questions within a 30-second window using local LLMs, RAG, and agentic techniques.

## Technical Constraints & Rules
- **Local Execution:** Models must be run locally using open-weights. **NO external LLM APIs** (like OpenAI or Gemini API) are allowed for answering.
- **RAG Guidelines:** 
    - Real-time search APIs must be free/non-paid.
    - Search results must be raw content (HTML/PDF), NOT answers generated by another LLM.
- **Time Limit:** Questions have a strict **30-second timeout**.
- **Agentic AI:** Tool calling (calculators, etc.) and combining multiple model predictions are highly encouraged.
- **API Interaction:** Use the provided `millionaire_client` library to interact with the game server at `http://131.175.15.22:51111/`.

## Project Structure
- `millionaire_client/`: Python package for API interaction.
- `ressources/`: Read-only reference materials. **DO NOT MODIFY.**
    - `assignment_description.pdf`: Full assignment details and marking criteria.
    - `PoliMillionaire.ipynb`: Reference notebook with API tutorial.
- `gemma_baseline.py`: Baseline implementation using Gemma model.
- `main.py`: Entry point for the application.
